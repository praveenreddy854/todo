## Project structure

### UI/ UX:

- /pg-todos is UI/UX for the application.
- It is a React application that uses the Material-UI library for the UI.
- It is a simple application that allows you to add, edit, and delete todo items.
- Use can either use the application as a todo list or as a chatbot to add, edit, and delete todo items.

### Backend:

- /pg-todos-api is the backend for the application.
- It is a Node.js application that uses the OpenAI API to generate todo items based on the user's query.
